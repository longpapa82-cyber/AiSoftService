## 0. 핵심 문제 & 방향

### 노랑의 근본 특성 (Python 실측)
| 색 | 화이트 위 | 다크 위 | 노랑채움 위 검정 |
|---|---|---|---|
| #facc15 (순노랑) | **1.53 미달** | 12.52 AA | 12.93 AA |
| #92610a (딥골드) | **5.33 AA** | — | — |
| #a16207 (딥골드) | 4.92 AA | — | — |

→ **순노랑은 화이트 배경 텍스트로 불가**(1.53). 스카이(v7)와 정반대로,
노랑은 화이트용 딥버전이 "갈색빛 골드"로 색이 크게 변함.

### 확정 방향 (사용자 결정: 노랑은 채움·다크·로고, 화이트 텍스트는 딥골드)
카카오·Snapchat 방식 — 노랑을 **투톤**으로 적재적소 배치:
- **채움/큰 요소/로고**: `#facc15` (순노랑, 화려)
- **채움 위 텍스트**: `#1a1200` (near-black, 12.13 AA)
- **화이트 섹션 텍스트**: `#92610a` (딥골드, 5.33 AA)
- **다크섹션 포인트**: `#facc15` (순노랑, 12.52 AA — 노랑 최대 강점)
- **아이콘 워시**: `#fef9c3`(amber-50) 배경 + `#a16207` 아이콘(4.58 AA)

## 1. 변경할 토큰 (tokens.css) — 스카이→노랑

| 토큰 | v7 (스카이) | v8 (노랑) | 용도 |
|---|---|---|---|
| `--ais-accent-primary` | #0284c7 | **#facc15** | 채움/큰 요소 |
| `--ais-accent-primary-ink` | #0369a1 | **#92610a** | 화이트 위 텍스트(AA) |
| `--ais-accent-primary-soft` | #e0f2fe | **#fef9c3** (amber-50) | 옅은 워시 |
| `--ais-brand` / `-2` | #0284c7 / #0369a1 | **#facc15 / #92610a** | 로고·브랜드 |
| `--ais-brand-grad` | 스카이 | **linear-gradient(135deg, #fde047, #facc15)** 노랑 | 로고·CTA |
| `--ais-ai-grad` (Hero "AI") | 스카이 | **linear-gradient(135deg, #fde047, #f5b400)** 노랑 | Hero "AI" |
| `--ais-gold/-2/-deep` | #0284c7 류 | **#facc15/#92610a/#a16207** | alias(원래 이름값 복원) |
| `--ais-dark-accent` | #56b6e8 | **#facc15** | 다크 "실시간"(순노랑) |
| `--ais-dark-accent-soft` | rgba(86,182,232) | **rgba(250,204,21,.1)** | 다크 워시 |
| `--ais-accent-highlight` | #38bdf8 | **#fde047** (yellow-300) | 보조 강조 |
| `--ais-accent-highlight-*` | 스카이 | **노랑 계열** | 보조 |
| `--ais-glow` | rgba(2,132,199,.28) | **rgba(250,204,21,.38)** | 글로우 |
| `--ais-neon-gold` | 스카이 rgba | **rgba(250,204,21)** | hover 강조 |

**핵심**: 토큰 값만 전환 → 참조처 자동 전파(확립된 구조). `--ais-*` 이름은
원래 "gold"였으니 값이 노랑으로 돌아가면 의미도 복원됨.

## 2. 배경별 적용 원칙 (투톤)

### 화이트 섹션 (Hero/About/서비스 밝은 것)
- **텍스트 강조**(About 리드·이브로우): `--ais-accent-primary-ink` = #92610a (딥골드, AA)
- **Hero "AI" 클립**: 노랑 그라디언트(#fde047→#f5b400) — 큰 면적이라 순노랑 OK
- **아이콘**: amber-50 배경 + 딥골드 아이콘
- **로고**: 노랑 그라디언트

### 채움 버튼 (CTA 등 primary 채움)
- 배경 #facc15 + **검정 텍스트**(#1a1200) — 흰 텍스트 불가(1.53)
- ⚠️ **검증 필수**: Button/StoreBadges primary가 흰 텍스트를 쓰는지 확인.
  - StoreBadges primary는 67번서 **near-black 배경+흰 텍스트**로 통일 → 노랑 전환 무영향(좌측 액센트바만 브랜드색=노랑). 유지.
  - 채움에 노랑을 쓰는 버튼이 있으면 텍스트를 검정으로.

### 다크 섹션 (Technology/Footer)
- 수치·포인트: `--ais-dark-accent` = #facc15 (순노랑, 12.52 AA) — 노랑 최대 강점

### 서비스 섹션 (PromoSection ×6)
- 각 서비스 `--p-*` 브랜드색 유지(정체성) — 이번 대상 아님

## 3. 웹 아이콘 (파비콘) — 요청 포함

현재 스카이(#38bdf8→#0284c7). 노랑 계열로 재생성:
- `favicon.svg` (탭, 라운드): 그라디언트 **#fde047→#f5b400**
- `apple-touch-icon.svg` (홈화면, 꽉 찬 사각): 동일 노랑 그라디언트
  - ⚠️ 흰 중앙 원 유지 — 단, **노랑 배경 위 흰 원은 대비 낮음**(장식이라 무관하나
    아이콘 인식성 위해 중앙 심볼을 near-black 원/글자로 바꿀지 검토)
- PNG 4종 + favicon.ico 재생성 (Playwright + Pillow, 동일 파이프라인)

## 4. 실행 순서

```
Step 1: tokens.css 스카이→노랑 값 전환 (자동 전파)
Step 2: 채움 버튼 텍스트색 검증/조정 (노랑 위 검정 확인)
Step 3: 파비콘 SVG 노랑 재생성 + PNG/ico (중앙 심볼 대비 검토)
Step 4: 빌드 + Python 대비 재검증 (화이트 #92610a 5.33 / 다크 #facc15 12.52 / 채움 위 검정 12.13)
Step 5: 전 섹션 실렌더 (화이트/다크 포인트·가독성·노랑 버튼 라벨)
Step 6: 커밋 + 배포 + CDN 전파 확인
```

**원칙**: 토큰 값만 전환, transform/opacity 모션 무변경, WCAG AA 실계산,
모바일 오버플로우 0, 서비스 --p-* 무변경.

## 5. 리스크 & 확인
- ⚠️ **노랑은 화이트 위 텍스트가 취약** → 반드시 -ink(#92610a) 사용, 순노랑(#facc15)은 채움/다크 전용.
- ⚠️ **노랑 채움 버튼 위 흰 텍스트 금지**(1.53) → 검정 라벨. 현재 near-black 통일 버튼은 무영향.
- ⚠️ 파비콘 노랑 배경 위 흰 원 인식성 → near-black 심볼 검토.
- Hero "AI" 그라디언트가 너무 밝으면(화이트 위) 흐림 → 딥쪽(#f5b400) 비중 확보.

## 6. 예상 효과
- **브랜드 개성 회복**: 스카이(AI 테크 표준색)보다 노랑/골드가 차별적·따뜻함(본래 Signal Gold 복원)
- **다크섹션 화려**: Technology "실시간" #facc15가 검은 배경서 가장 빛남
- **가독성 유지**: 화이트 텍스트는 딥골드(AA), 채움은 검정 라벨(AA)
